键鼠操作说明（点击收起或展开）
  • A / D：向左 / 向右移动
  • S：静止时蹲下；移动时滑铲
  • S + W / Space：从单向平台下穿
  • W / Space：跳跃；空中再次按下可冲刺
  • F：近战攻击
  • 鼠标移动：瞄准
  • 鼠标左键按住：连续射击
  • 鼠标右键按住：发射并维持钩爪；松开结束
  • A / D：向左 / 向右移动
  • W / Space：跳跃（不再兼任空中冲刺）
  • Shift：移动时地面滑铲；空中冲刺
  • S：蹲下；S + 跳跃可穿过单向平台
  • J：近战攻击
  • K / 鼠标左键：开火（当前仍是旧连续射击逻辑）
  • U / 鼠标右键：钩索按住使用、松开释放
  • 鼠标移动：瞄准

实验模式 #m1-controls：仅验证新版输入和 M1 动作衔接，二段跳、短滑铲和单发蓄压枪尚未实现，不代表正式版已迁移。

键盘操作在页面获得焦点时生效；鼠标射击和钩爪请在游戏画布内按下。
