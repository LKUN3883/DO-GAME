## 本轮补上的主要缺口

1. 重生最后执行，一帧输入锁完整保留，锁帧不产生按下/松开边缘，瞄准固定Facing；状态、近战、姿态、提示和钩爪完整清理。投射物在cleanup阶段清空，普通敌世界状态不重置。
2. 玩家与敌/ACTIVE Boss按最小轴挤出、tie优先X，身体接触不伤人；不改敌位置速度，仅地形二次修正可能清玩家速度。角色间使用2eps分离以退出4.3闭区间接触判定；地形仍按实际穿透分离。
3. 蹲滑变高保持脚底，低顶不能站或匍匐；滑铲第一帧速度10、不能转向，撞墙/离地/0.9s结束。拉拽离地后不会恢复陈旧滑铲。
4. 敌近战边缘感知和无负冷却积攒；远程视线遮挡；严格最近目标与Unicode code point排序。
5. 攻击生成收口到相机、敌和Boss更新之后，真实spawn_seq按玩家→敌→Boss递增，新投射物当帧移动。命中与伤害分离，玩家同帧只承受最大伤害，iFrame中命中子弹仍销毁。
6. 拉拽的STUCK进度在地形与角色挤出后用最终位置计算，避免有推进速度却永远拉不动的PULL。钩爪完整生命周期与最新锚点/目标死亡/释放/卡住交互，保持第14章数值。
7. 固定持续时间按60Hz整帧处理，避免浮点残差给0.2s预警、0.45s判定期、0.5s停顿等多留一帧；频率射击仍使用原RateTimer。新Hint在创建tick不提前扣时。
8. 触发Boss同帧切镜头范围；延迟死亡事件和WIN冻结；检查点Hint、8×8 Facing三角、主体精确颜色。Trigger/Checkpoint/Goal不再冒充没有阻挡作用的灰色地形。
